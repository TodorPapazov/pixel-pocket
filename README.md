# PIXEL POCKET

Play NES, Super NES, Game Boy, Game Boy Color, GBA, DS, N64, and PS1 in the browser. Install it on Windows 10, Windows 11, or Mac, keep playing with no Wi-Fi, and sync pockets across phone, iPad, and computer when you sign in.

PIXEL POCKET does not host copyrighted games. Load a file from your computer, or paste an Archive.org link.

## Run

```bash
npm install
npm run dev
```

`npm run typecheck` checks the project. `npm run build` builds it.

Sign-in and cloud pockets need `DATABASE_URL` and the auth provider keys in the environment. Do not commit those.
